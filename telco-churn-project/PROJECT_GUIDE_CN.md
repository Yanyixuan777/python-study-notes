# 项目交付说明

作者：`yanyixuan`

这个项目使用 IBM Telco Customer Churn 数据，完成了课程要求的四部分：数据摘要、EDA 计划与结果、数据清理与特征工程、假设检验与结论。

报告文件是 `IBM_Telco_Churn_EDA_Report.pdf`。脚本 `analysis.py` 会重新下载公开数据并生成图表、统计表和处理后的特征矩阵；`build_report.py` 会把这些结果排版成 PDF。

最重要的发现是：确认样本中，月付合同客户流失率为 43.7%，一年或两年合同客户为 6.0%，差异为 37.7 个百分点。这个结果说明月付客户应该优先进入留存实验，但它是相关关系，不能直接写成因果结论。

报告还检验了三个预先写好的假设：合同类型与流失有关、流失客户月费更高、付款方式与流失有关。三个检验都通过了 Bonferroni 校正。工程部分包括 `TotalCharges` 类型修正、缺失值指示变量、训练集内中位数填补、标准化、one-hot 编码、对数变换和新客户交互特征。
